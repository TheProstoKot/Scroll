# Scroll.exe
У меня не работает колёсико мыши на клавиатуре, а играть в игры хочется. Как пример, приведу HOI4, где приближаться можно только с помощью колёсика мыши. К сожалению, других способов я не нашёл, так что написал этот скрипт. Он позволяет крутить колёсико вверх (Numpad1) и вниз (Numpad0) при нажатии на клавиши. Не обращайте внимания на названия переменных и прочую ерунду, скрипт генерила нейронка и скорее всего он больше не будет дорабатываться.

Команда для компиляции: `g++ scroll.cpp -o scroll.exe -static -O2 -mwindows -lshell32`
